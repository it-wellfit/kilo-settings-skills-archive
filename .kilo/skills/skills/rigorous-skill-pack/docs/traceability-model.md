# 追溯模型 (Traceability Model)

**版本**: v1.0.0  
**日期**: 2026-10-26

---

## 追溯鏈

每個必須透過以下鏈條追溯：

需求 ID/PRD → 系統設計/ADR → 合約 → 工單 → 實作/Git 提交 → 自動化測試 → 發布證據 → 回顧

## 追溯矩陣欄位

| 欄位 | 說明 |
|------|------|
| 需求 ID | 可追溯的需求識別碼 |
| 規格 | 對應的規格文件 |
| 程式碼 | 對應的程式碼位置 |
| 合約 | 對應的 API/介面合約 |
| 測試 | 對應的測試案例 |
| 狀態 | verified / validated / blocked |

## 實際證據

合成測試通過僅驗證符合性，不驗證真實使用者價值。所有狀態必須有連結的證據。
