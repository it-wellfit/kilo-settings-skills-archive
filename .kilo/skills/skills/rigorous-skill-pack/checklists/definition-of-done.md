# Definition of Done (定義完成)

**版本**: v1.0.0

---

## 通用 DoD

- [ ] 需求具有可追溯 ID
- [ ] PRD 已完成並被審查
- [ ] ADR 已記錄決策與原因
- [ ] 每個工單有明確 DoD
- [ ] 測試先行（紅綠重構）
- [ ] 100% 測試通過
- [ ] 零警告 (clippy)
- [ ] `#![forbid(unsafe_code)]` (Rust 專案)
- [ ] 程式碼審查通過 (行為 + 架構)
- [ ] 回滾證明已記錄
- [ ] 安全審查通過
- [ ] 威脅模型已完成
- [ ] 最小權限原則已驗證
- [ ] 發布檢查表已執行
- [ ] 回滾程序已驗證
- [ ] 備份還原已測試

## 實際證據要求

每個 DoD 項目必須有可觀察證據，不接受僅由 AI 自稱完成。
