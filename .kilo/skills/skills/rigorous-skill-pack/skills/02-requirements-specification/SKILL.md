# 02-Requirements Specification 需求與領域建模

## 用途

將需求轉成規格、領域模型與邊界，建立可追溯的需求 ID 與追溯矩陣。

## 輸出

- PRD (`templates/prd.md`)
- 領域模型
- 追溯矩陣

## 執行步驟

1. 消除規格歧義，形成決策共識
2. 記錄未解決項目而非臆測
3. 為每個需求指派可追溯 ID
4. 定義領域邊界

## 品質閘門

- [ ] PRD 已完成並被審查
- [ ] 需求具有可追溯 ID
- [ ] 領域邊界已定義

## 停止條件

需求歧義未消除時，停止並釐清。

## AI 自稱完成 vs 實際證據

僅接受 PRD 檔案存在且追溯矩陣完整的實際證據，不接受 AI 僅說「需求已定義」。
