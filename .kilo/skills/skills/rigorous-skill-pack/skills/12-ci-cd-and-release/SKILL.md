# 12-CI-CD and Release CI/CD 與發布

## 用途

執行建置、測試、部署、回滾與備份還原，確保發布可回滾且備份可還原。

## 輸出

- 發布檢查表 (`templates/release-checklist.md`)
- 部署記錄
- 回滾程序
- 備份還原記錄

## 執行步驟

1. 執行發布檢查表
2. 驗證部署回滾程序
3. 測試備份還原
4. 啟用可觀測性

## 品質閘門

- [ ] 發布檢查表已執行
- [ ] 回滾程序已驗證
- [ ] 備份還原已測試
- [ ] 可觀測性已啟用

## 停止條件

部署回滾測試未通過時，停止發布。

## AI 自稱完成 vs 實際證據

僅接受發布檢查表、回滾測試與備份還原結果的實際證據，不接受 AI 僅說「已發布」。
