# 評估結果 (Eval Results)

**版本**: v1.0.0  
**日期**: 2026-10-26  
**狀態**: 待執行

---

## 說明

本目錄用於記錄 12 個評估案例的執行結果。每個案例的結果必須包含實際證據，不僅接受 AI 自稱完成。

## 結果檔案命名

`EV-####-<案例名稱>-result.md`

例如：`EV-001-產品探索-價值假設驗證-result.md`

## 結果欄位

| 欄位 | 說明 |
|------|------|
| 案例 ID | 例如 EV-001 |
| 案例標題 | 例如 產品探索 - 價值假設驗證 |
| 執行日期 | YYYY-MM-DD |
| 執行環境 | IDE、模型、版本 |
| 結果 | PASS / FAIL / BLOCKED |
| 實際證據 | 檔案路徑、命令退出碼、測試報告 |
| 停止條件觸發 | 是 / 否 |
| 備註 | 說明 |

## 目前狀態

本版本為 v1.0.0 基礎版，12 個評估案例尚未在所有 AI 模型與 IDE 上端到端跑完。請針對你的開發環境和實際專案持續測試、修正與演進。
