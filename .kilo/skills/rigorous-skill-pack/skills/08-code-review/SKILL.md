# 08-Code Review 程式碼審查

## 用途

執行行為與架構雙盲審查，附帶形式化回滾證明，確保變更可回滾。

## 輸出

- 審查報告
- 回滾證明
- PR/MR

## 執行步驟

1. 行為審查：驗證功能正確性
2. 架構審查：驗證與現有架構一致性
3. 記錄回滾證明（如何回滾此變更）
4. 提交 PR/MR

## 品質閘門

- [ ] 行為審查通過
- [ ] 架構審查通過
- [ ] 回滾證明已記錄

## 停止條件

審查未通過時，停止並修正。

## AI 自稱完成 vs 實際證據

僅接受審查報告與回滾證明檔案存在的實際證據，不接受 AI 僅說「審查已通過」。
