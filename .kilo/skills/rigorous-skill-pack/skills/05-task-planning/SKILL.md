# 05-Task Planning 任務規劃

## 用途

將規格拆解為 DAG 工單，每個工單適合單一上下文視窗，標註依賴關係。

## 輸出

- 任務清單
- DAG 工單
- 依賴關係

## 執行步驟

1. 將規格拆解為獨立工單
2. 標註每個工單的定義完成 (DoD)
3. 標註工單間依賴關係
4. 確認工單大小適合單一上下文視窗

## 品質閘門

- [ ] 每個工單有明確定義完成 (DoD)
- [ ] 工單間依賴已標註
- [ ] 工單大小適合單一上下文視窗

## 停止條件

工單過大或依賴環狀時，停止並重新拆解。

## AI 自稱完成 vs 實際證據

僅接受任務清單與 DAG 工單檔案存在的實際證據，不接受 AI 僅說「任務已規劃」。
