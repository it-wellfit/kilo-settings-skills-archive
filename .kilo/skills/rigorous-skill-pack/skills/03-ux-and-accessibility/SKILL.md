# 03-UX and Accessibility UX 與無障礙

## 用途

確保介面可用且符合無障礙標準，支援鍵盤導航與色彩對比標準。

## 輸出

- UX 規劃
- 無障礙檢查表 (`checklists/`)
- 原型（如適用）

## 執行步驟

1. 執行無障礙檢查表
2. 驗證鍵盤導航可用
3. 驗證色彩對比符合標準
4. 記錄發現與修正

## 品質閘門

- [ ] 無障礙檢查表已執行
- [ ] 鍵盤導航可用
- [ ] 色彩對比符合標準

## 停止條件

無障礙檢查未通過時，停止並修正。

## AI 自稱完成 vs 實際證據

僅接受無障礙檢查表執行記錄的實際證據，不接受 AI 僅說「UX 已完成」。
